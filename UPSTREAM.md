# Upstream research and attribution

TwiOpSec is an independently written, configuration-compatible successor. It
does not copy or bundle source from the projects below because neither source
repository included an explicit software license when reviewed on 2026-09-14.

The compatibility target and original idea are credited to:

- **T2C-OPSecurity**, by JaTiTV / T2Code:
  <https://git.t2code.net/JaTiTV/T2C-OPSecurity>
  (reviewed commit `d45a9726e4216b66ee01d68cab33a6bb2c992894`)
- **T2CodeLib**, by JaTiTV and contributors including Jkobs:
  <https://git.t2code.net/JaTiTV/T2CodeLib>
  (reviewed commit `79a1548183135ce64a8c2db0d3d6ba0251dd19aa`)

The names T2C-OPSecurity, T2CodeLib, T2Code, Paper, Folia, Minecraft,
EssentialsX, and LuckPerms belong to their respective owners. Compatibility
references do not imply endorsement or affiliation.

No T2CodeLib runtime is required: the small facilities TwiOpSec needs for
configuration, scheduling, messaging, and auditing are implemented inside the
`com.siberanka.twiopsec` namespace and shipped in the one plugin JAR.
